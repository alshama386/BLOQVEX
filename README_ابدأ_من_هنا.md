# 🧩 BLOQVEX — بلوكڤكس | النسخة 1.0

**الشعار الرسمي معتمد:** المكعب الأصفر المبتسم واسم BLOQVEX الملون. جميع ملفات الصورة داخل `assets/`.

## 🎮 شنو موجود في المشروع؟
- لعبة مكعبات حقيقية على لوحة 8×8؛ لمس، سحب، اختيار قطعة ثم لمس اللوحة، مسح الصفوف/الأعمدة، كومبو، نقاط، انتهاء عند عدم وجود نقلات.
- **3 أوضاع فردية:** Classic (بلا وقت)، Sprint (120 ثانية)، Daily (بداية ثابتة بنفس اليوم).
- **أونلاين (بعد ربط Supabase):** حسابات إيميل، أسماء لاعبين ودول، نتائج عالمية، هدايا يومية، ثيمات بالألعاب، أصدقاء وطلبات، دردشة نصية بين الأصدقاء، مواجهات مباشرة بين لاعبين بغرف رمز 6 أحرف ومدتها 120 ثانية، إعلانات إدارية.
- **بدون أي ربط:** اللعب الفردي والنتائج المحلية والثيمات والهدية اليومية تعمل مباشرة كضيف.
- عربي/إنجليزي، مناسب لشاشة الآيفون والأندرويد والكمبيوتر، PWA قابل للإضافة للشاشة الرئيسية.
- لا تحتاج `npm install` أو عملية build لرفع الموقع.

## 🚀 أسرع طريقة للبدء من الآيفون (GitHub + Netlify)
1. فك ضغط ملف `BLOQVEX_FULL_PROJECT.zip`.
2. ارفع **محتويات المجلد الداخلي** إلى مستودع GitHub جديد. يجب أن يكون `index.html` في جذر المستودع الذي سيُنشر.
3. في Netlify اربط المستودع: **Build command فارغ**، و **Publish directory**: `.` (أو اتركه حسب `netlify.toml`).
4. افتح رابط Netlify؛ راح تشتغل اللعبة كضيف فوراً.
5. لتفعيل الحسابات والمواجهات، كمل خطوات Supabase التالية.

## ☁️ تفعيل Supabase (مرة وحدة)
1. افتح مشروع **جديد** في [Supabase](https://supabase.com/dashboard).
2. افتح **SQL Editor** وانسخ نص الملف `supabase/schema.sql` كاملاً، ثم اضغط **Run**. لا تشغّله على مشروع قديم فيه جداول تحمل نفس الأسماء إلا إذا فحصت التعارضات.
3. من **Project Settings → API** انسخ:
   - `Project URL` (يبدأ بـ `https://`)
   - `publishable / anon key` **العام فقط**؛ لا تستخدم أبداً `service_role` أو secret key.
4. افتح `config.js` في GitHub وعدّل الحقلين:
   ```js
   window.BLOQVEX_CONFIG = {
     SUPABASE_URL: 'https://YOUR-PROJECT.supabase.co',
     SUPABASE_ANON_KEY: 'YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY'
   };
   ```
5. Supabase → **Authentication → URL Configuration**: ضع عنوان Netlify في **Site URL** وأضف نفس عنوان الموقع في **Redirect URLs** (للرسائل والتفعيل). تأكد من إعدادات إرسال وتأكيد البريد.
6. ادخل لعبتك، أنشئ حساباً جديداً، وفعّل الإيميل إذا طُلب منك.

### 🛡️ تفعيل حساب المالك كمدير
**المدير ما يتحدد بالإيميل داخل كود الواجهة**؛ الصلاحية بالداتابيس حصراً.
1. سجّل حسابك في الموقع.
2. في Supabase → Authentication → Users، انسخ **UUID** لحسابك.
3. افتح SQL Editor ونفّذ (استبدل الـ UUID فقط):
   ```sql
   UPDATE public.profiles SET role='admin' WHERE id='YOUR_ACCOUNT_UUID';
   ```
4. سجل خروج وادخل مرة ثانية / حدّث الصفحة؛ يظهر قسم **الإدارة** في القائمة الجانبية. فيه إرسال إشعار للجميع أو UUID لاعب محدد.

## 🧪 تجربة على الكمبيوتر
`npm run dev` ثم افتح `http://localhost:8000` (يحتاج Node.js 18+، بلا تثبيت حزم).
`npm test` يشغّل اختبارات محرك اللعبة.

## 📁 الملفات المهمة
- `index.html` — الواجهات الرئيسية.
- `styles.css` — التصميم المتجاوب.
- `src/app.js` — التنقل والتفاعل واللعب والغرف.
- `src/game.js` — محرك اللعبة مع مولّد القطع.
- `src/backend.js` — ربط Supabase، حسابات وغرف ورسائل.
- `src/i18n.js` — عربي وإنجليزي.
- `supabase/schema.sql` — الجداول والسياسات والصلاحيات وعمليات الخادم.
- `assets/` — الشعار وأيقونات التطبيق.
- `manifest.webmanifest`, `sw.js` — تثبيت PWA والعمل بدون شبكة للأجزاء المحفوظة.
- `netlify.toml` — إعداد نشر Netlify وحمايات الرؤوس.
